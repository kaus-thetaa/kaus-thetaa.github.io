The problem.

Rocket testing needs a readable place to inspect telemetry, exercise hardware workflows and understand flight data.

What I built.

A browser-based ThrustMIT ground station with display, telemetry, motor-test and CSV-filtering modes.

The telemetry view groups flight, sensor, environment, GPS, radio, continuity and battery panels. Flight state is derived from barometric pressure and altitude, and session data can be downloaded as CSV.

What it does.

Each hardware mode includes simulated data; compatible desktop browsers can connect through Web Serial.

The constraints.

Active development. Web Serial requires a supported desktop browser and connected hardware; simulated data is available for exploring the interface.
