ORBIT Gesture Studio

A webcam. A gesture. Your desktop.

ORBIT
Concept studyORBIT Gesture Studio

The problem.

Turn a hand gesture into a useful desktop action, with control over when it runs.

What I built.

A gesture studio with live recognition, configurable mappings and a disarmed-by-default action system.

Static hand poses map to approved desktop actions. The studio lets you tune thresholds and test mappings before arming the system. Camera frames stay in memory.

What it does.

Explicit action allowlist. Emergency stop. Local camera processing.

The constraints.

Motion gestures are experimental. The repository demo uses simulated landmarks, and synthetic tests do not establish real-world recognition accuracy.
