Static Fire Ground Station

From serial data to a clear decision.

Acquire.Understand.Act.
Signal to system.
Concept studyStatic Fire Ground Station

The problem.

Static-fire testing needs readable telemetry and explicit operator controls.

What I built.

A PyQt6 ground station with serial input, live plots, interlocked states, simulation mode and CSV logging.

The desktop app starts in simulation mode. Its state machine separates safe, armed, burn and complete states, while session data is written to CSV. A browser demo makes the workflow inspectable.

What it does.

A browser simulation lets you explore the interface without hardware.

The constraints.

The browser experience is a simulation. It is not an independently certified safety system.
