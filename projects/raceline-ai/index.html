RaceLine-AI

Learning the racing line.

  • Python
  • PyGame
  • Stable-Baselines3
  • FastAPI

The problem

Can an agent learn to drive a circuit from feedback instead of a scripted racing line?

What I built

A custom racing environment, PPO training pipeline and browser dashboard for inspecting laps, crashes and replay data.

The environment models drag, grip and rolling resistance. Observations describe speed, alignment and track position; rewards combine forward progress, crashes and completed laps.

What the system does

From simulation to training to a shareable, data-driven dashboard.

The constraints

A simulated learning environment, not a real vehicle controller. No lap-time improvement claim is made without a sourced training run.

Implementation details are documented in the project README. No unsourced performance metrics are used here.

Inside the system

  1. Track state
  2. PPO policy
  3. Steer + throttle
  4. Reward feedback
