The problem

Finding a file should not mean remembering what you named it.

What I built

An offline Windows assistant that searches, summarizes and organizes files using a local language model and semantic search.

Phi-3 Mini handles language tasks while sentence-transformers and ChromaDB make documents searchable by meaning. The interface separates the proposed action from its execution, and duplicate removal uses the recycle bin.

What the system does

Local inference. Review-before-apply file actions. Recoverable deletion.

The constraints

Requires a Windows machine and local model installation. Performance depends on available hardware.

Implementation details are documented in the project README. No unsourced performance metrics are used here.
